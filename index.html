Why Air-Gap?

상시 연결된 백업은 안전하지 않습니다

소프트웨어적 차단만으로는 지능형 랜섬웨어의 동시 감염 공격을 막을 수 없습니다.

기존 소프트웨어 백업의 위험

네트워크가 항상 연결되어 있어 1차 감염 시 백업본까지 표적이 됩니다.

  • 운영 서버 감염 시 백업 스토리지 동시 암호화
  • 백업 계정 탈취 시 백업본 원격 삭제 및 변조 위험
  • 네트워크 경로를 통한 2차 랜섬웨어 확산

이음코어 AGBS 물리적 격리

하드웨어 릴레이를 통해 백업 경로를 물리적으로 단선(Air-Gap)합니다.

  • 물리적 하드웨어 차단: 평상시 외부망과 완벽 단절
  • Pull 방식 격리 동기화: 독립망 내 안전한 데이터 수집
  • 하드웨어 인터락: 두 경로의 동시 연결 원천 방지
How it Works

AGBS 아키텍처 및 동작 메커니즘

백업 전후로 스위치를 자동 전환하여 물리적 에어갭 환경을 완성합니다.

[상태 A] 사전 백업 단계 (Pre Job ~ Main Job)

#1 스위치 ON (내부 업무망 연결)
운영 서버(ERP/DB/MES)에서 기업 #1 NAS로 기본 백업 데이터를 전송합니다. 이 시간 동안 #2 격리 독립망은 하드웨어적으로 완전 차단됩니다.

[상태 B] 격리 및 동기화 단계 (Post Job)

#2 스위치 ON (격리 독립망 연결)
#1 NAS를 내부망에서 물리적으로 차단하여 에어갭을 완성합니다. 최후의 보루인 #2 NAS가 독립망 내에서 주도적으로 데이터를 가져와(Pull) 안전하게 복제합니다.

Key Features

타협 없는 하드웨어 신뢰성

엔터프라이즈 환경을 위한 견고한 설계와 직관적인 통합을 제공합니다.

⚡

하드웨어 인터락

NC/NO 배타 릴레이 제어를 통해 어떤 상황에서도 두 경로가 동시 연결되지 않도록 물리 레벨에서 차단합니다.

🛡️

Pull 기반 보안 설계

침해 가능성이 있는 1차 NAS가 아닌, 물리 격리된 2차 최후 보루 NAS가 주도권을 갖고 데이터를 안전하게 수집합니다.

⚙️

독립 임베디드 코어

신뢰성 높은 MCU와 유선 이더넷 하드웨어 로직을 기반으로 외부 OS 의존성 없이 무중단으로 구동됩니다.

🔄

기존 인프라 무중단 연동

기존에 운용 중인 백업 소프트웨어 스크립트 및 NAS 환경(Synology, QNAP 등)과 유연하게 연동 가능합니다.
